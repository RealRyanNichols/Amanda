# 2026-04-20 — Wordmark ideas Ryan floated

Captured for future wordmark / logotype iterations.

## "G-as-A" concept — the real idea is AIDEON

Ryan clarified 2026-04-20 (second message): *"The A eye for Gideon was
supposed to be AIDEON. IG was supposed to look like an A but that's
it. The G just looks like an A so it would be AIDEON."*

Parse: the **G** glyph is drawn so that it reads visually as an **A**.
Everything else in the wordmark is unchanged — I-D-E-O-N follow
normally. So the word reads:

- Correctly: **GIDEON** (when you know the brand)
- First-glance / stylized: **AIDEON** (when the G's aperture looks
  like an A's crossbar + angled strokes)

The hidden reading "AIDEON" contains **AI** in the first two letters
— a literal product-category Easter egg baked into the name.

Why it's interesting:
- "Aiden" is a common first name — Celtic origin meaning "little fire."
  Ties directly to our flame motif. Second hidden reading is a
  theological/brand Easter egg.
- AI shows up naturally in the letters (A + I + D + N) — the product
  category is literally hidden inside the name.
- Premium brands often play this game (FedEx arrow, Amazon a→z,
  Toblerone bear). Done well it's an insider signal.

Risks:
- Can read as too clever or gimmicky at small sizes (favicon,
  messaging avatar).
- Wordmark legibility drops when you force dual-reading.
- Requires exceptional type design. Not a pure Inter-700 solve.

## Other shortening / stylization ideas

- **GIDEON** (canonical wordmark, Inter 700, 0.08em letter-spacing,
  gold gradient) — the current spec.
- **GDN** — very tight 3-letter short form. Reads like a stock ticker.
- **G.** — single-glyph brand with a period for weight (cf. "Notion"
  but shorter). Paired with the full "Gideon" name spelled out on
  first mention.
- **G|** — G with a vertical bar suggesting the sword. Abstract.
- **AIDN** — the "G-as-A" variant Ryan mentioned. Works only with
  custom type.

## Ryan's decision for now

> "For right now, Gideon AI is fine."

So we ship the straightforward wordmark **GIDEON** with the flame
glyph, tab label **Gideon AI**. The G-as-A custom logotype becomes a
V2 project after we've proven the product. Good custom type work is
$8–25k; not worth it until the name has earned it.

## If Ryan pulls the trigger later

When we do commission a custom logotype, brief the designer with:
- Must read as GIDEON at first glance.
- Must read as AIDN / AIDEN at second glance.
- Must survive favicon / 16px.
- Must work on gold-on-night AND night-on-cream.
- Geometric, sharp, warrior-coded — not organic/soft.
- Recommended designers: Berger & Föhr, Ueno, Manual, Character SF,
  or a hand-drawn type specialist (Dan Cassaro tier).
